# Filled Boxes and Loose Notebooks Calculator

## Description

This program determines the number of boxes packed and the number of left over notebooks.

## How to Run

1. Open the program file.

2. Run the program.

3. Enter the total number of notebooks.

4. Enter the capacity of one box.

5. Check the number of boxes filled and loose notebooks.

## Input Needed

- total number of notebooks (notebooks)

- total capacity of a box (box_capacity)

## Sample Output

If the number of notebooks is greater than the box capacity:

Total number of notebooks:67

How many can fit in a box:13

the number of full boxes is 5

the number of loose notebooks is 2


If the number of notebooks is less than the box capacity:

Total number of notebooks:9

How many can fit in a box:10

the number of full boxes is 0

the number of loose notebooks is 9

no box was filled
